Read-only is structural.

There is no write path into the project. The page cannot save, rename or format what you are reading.

Comments are prose.

The only English in a source file is set in the reading face; the voice changes even when the line does not.

Indentation is drawn.

Leading whitespace becomes a hairline gutter; a block has a shape before it has a count.

Long lines admit it.

A wrapped expression carries ↳ in the margin, so it never reads as a new line.

The cursor is a reading position.

A ribbon and a 14-alpha wash, not a blinking caret.

Six atmospheres

Each is a paper, an ink and a tonal ladder — a place, not a light/dark switch. 1–6 changes the page you are reading.

Run it

A native binary for macOS and Linux. Windows is written for but untested. Zero bundled assets: no fonts, no icons, no images come with the reader.

Built against egui/eframe 0.35. Requires rustc ≥ 1.92. Language servers are discovered, never installed.

git clone https://github.com/dovidio/zenith
cd zenith
cargo run --release -- ~/code/some-project

The room

A native code reader for projects where people read code rather than write it — reviewing, onboarding, archaeology, study. Not an editor with the editing removed: the whole interface assumes you will never type a character into it.

The page opens alone. A small bloom above it opens the index, the contents, the launcher and settings — one surface at a time, gone when it is done. Read-only is not a mode here; it is the shape of the room.

Markdown files render as documents; # inside a fence stays code. Comments are set in the reading face, indentation is drawn as hairlines, and long lines wrap with ↳ in the margin.

It does not change your code

Files are opened with std::fs::read; there is no save, no lockfile, and no cache directory inside the repository. Its own state — theme, typography, measure, reading positions, bookmarks — lives in ~/.config/zenith/, and if that is not writable it degrades to an in-memory session.

The only thing it may start on your behalf is a language server, and only for a folder you have opened. It answers one question — where is this defined — and the outline; it never edits.

Read a codebase without the editor talking back.

The page is the product. Everything else is summoned, then returned.
